T5  DELEGATED SPEND -- PARTIALLY DERIVABLE
------------------------------------------
  sidechain calls in THIS ledger    0
  A subagent's calls are not in the coordinator's transcript, so
  the figures above are the COORDINATOR'S cost and nothing else.
  But the dispatch record is not empty: each completed agent reports
  a total at completion. What it reports, and what it does not:
    DORA metrics for today's releases           188,885 tok, 73 tool uses
  delegated, completed (1)       188,885
  delegated, still running (3)    UNDERIVABLE -- no total until it stops
  coordinator                        1,182,809,707
  ratio, as printed                  0.016%

  DO NOT READ THAT RATIO. It is two different units divided by each
  other. The coordinator figure is 99.5% cache reads; 188,885 tokens
  for 73 tool uses over 16 minutes cannot be -- a cached agent that
  busy would show tens of millions. The reported total is almost
  certainly billable-ish tokens with cache reads excluded or counted
  once. Set against the coordinator's non-cache-read spend
  (5,597,502), delegation is 3.3% -- a three-order-of-magnitude
  swing that depends entirely on which unit you picked, and NOTHING
  in the record says which one it is. That is the finding: the two
  ledgers do not share a denominator, so the sum of them is not a
  quantity. This is defect class 3 -- observation is not intent --
  and class 6: a verdict must name its build. A token count must
  name its counting rule or it cannot be added to another one.

  Two things that total CANNOT do, and both matter:
   1. It has no breakdown. One integer, no cache/input/output split,
      and those differ in price by 50x. It can be counted and cannot
      be PRICED. A cost-per-unit built on it is a volume metric
      wearing a dollar sign.
   2. It arrives only at completion. Three agents are running now and
      report nothing, so at any instant the live total is unknowable
      -- which is the read-after-write race from the guard work, in
      the ledger: 'not there' and 'not there YET' read identically.

  So the honest statement of the night's spend is a BOUND, not a
  number: at least 1,182,998,592 tokens, coordinator priced
  and delegation not. Defect class 1 -- unreachable is not falsified.

  a mandatory parent, so delegated spend is a row that is missing
